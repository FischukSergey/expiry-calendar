## 1) Решения

- CD не меняет JSON-контракты и пути `/api/v1`.
- Проба после выкладки: уже существующий `GET /healthz` (Sprint 1) с публичного HTTPS.
- OpenAPI не дополняем ради деплоя.

## 2) Что дергает CD

`GET https://duekeep.ru/healthz`

- анонимно;
- 200 — стек принят;
- иначе `deploy.sh` и job Actions завершаются с ошибкой.

Не использовать для готовности `/docs` или UI: они могут быть 200 при мёртвом API.
