# Known Limitations — Sprint 4

## Realtime

**Один процесс backend.** Hub в памяти. Второй инстанс не получит SSE.

**Пропущенные SSE при офлайне не буфер.** После reconnect — `GET /notifications`.

## Push

**Демо: Chrome + localhost.** iOS только у установленного PWA, не цель защиты.

**Нет UI подписки.** API есть, кнопка разрешения — Sprint 5.

**Пустые `VAPID_*` в env.** Процесс генерирует пару на старт; после рестарта старые подписки недействительны. В local compose ключи фиксируем.

## UI

Дашборд и календарь есть только как JSON.

## Дашборд

**Нет конвертации валют.** RUB и USD — отдельные объекты. `yearly / 12` — целое деление.

## Тесты

**Нет integration с Postgres.** Тикер, SSE, push, dashboard — httptest + память. `task test:integration` по-прежнему заглушка.

## Тикер

Интервал 60 с; в тестах — явный tick, не ждать минуту.

**После сдачи v1.** 60 с — удобство стенда, не требование домена (статус по календарному дню UTC). Сменить интервал. Настройки процесса (HTTP, JWT TTL, тикер, SSE ping и пр.) читать из файла конфига при старте, не только из env. В `.env` оставить только чувствительное (секреты, пароли, JWT, VAPID). Остальное — в конфиг.
