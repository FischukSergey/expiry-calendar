# Known Limitations — Sprint 5

## PWA

**Нет офлайн-редактирования.** Без сети — заглушка.

**Пуши нестабильны в Safari / iOS.** Демо — Chromium.

## CSV

**Нет авто-маппинга «умным» AI.** Только ручной маппинг колонок.

**Большие файлы.** Верхняя граница строк задаётся в коде (например 5_000); сверх — 422.

## Документация API

**Спека неполная до сверки Sprint 6.** UI `/docs` уже живой; в yaml нет ручек спринтов 2–5, пока их нет в коде.

## Seed

Объём 50+ может быть неполным до Sprint 6.
