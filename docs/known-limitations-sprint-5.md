# Known Limitations — Sprint 5

## PWA

**Нет офлайн-редактирования.** Без сети — заглушка `offline.html`.

**Пуши нестабильны в Safari / iOS.** Демо — Chromium на localhost.

**Подсказка установки.** `beforeinstallprompt` есть не у всех браузеров и часто не в первый заход (пока не зарегистрирован SW).

## CSV

**Нет авто-маппинга «умным» AI.** Ручной маппинг; если заголовки совпали с именами полей — подставляем.

**Большие файлы.** Import > 5_000 строк, export > 10_000 — 422 / обрезка по потолку.

## UI

**Нет экрана kinds.** Тип выбирается в форме записи из `GET /kinds`.

**Нет bulk в списке.** Ручка `POST /items/bulk` есть, кнопок в UI нет.

**SSE один процесс.** Hub в памяти; несколько реплик backend не делят события.

## Документация API

**Полная сверка OpenAPI — Sprint 6.** UI `/docs` живой; CSV и ручки 2–5 уже в yaml, но сводная сверка со всеми контрактами откладывается.

## Seed

Объём 50+ items, renewals и непрочитанных уведомлений — Sprint 6. Сейчас черновой набор (несколько записей).
