# Known Limitations — Sprint 7

## Продукт

**Нет почты.** Инвайт — ссылка, которую копирует хозяин.

**Один хозяин на org.** Второго admin не приглашаем; смены владельца нет.

**Kinds общие на инсталляцию.** Типы не копируются в org. Кто мутирует kinds (только seed-admin vs любой org-admin) — решить при реализации и не размазывать.

**Нет удаления org** и нет биллинга/квот.

## Auth

**`users.role` устаревает.** Источник прав — `org_members`. Колонку можно оставить для backfill.

**Несколько членств.** Если пользователь и хозяин своей org, и viewer чужой — полноценный переключатель пространств можно упростить: API accept + смена `org_id` в следующем access, без отдельного продукта «workspaces».

## Совместимость v1

**Демо-org** держит прежний общий seed. Сценарий сдачи Sprint 6 (admin+viewer видят одно) сохраняется **внутри** этой org.

**Новый register** больше не становится viewer демо-данных.

## Инфра

По-прежнему один инстанс backend, PWA, данные только на сервере, без офлайн-CRUD.
