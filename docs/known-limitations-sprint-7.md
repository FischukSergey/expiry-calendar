# Known Limitations — Sprint 7

## Продукт

**Нет org и шаринга.** Нет `org_id`, инвайтов, роли `viewer` для чужого каталога. Один аккаунт — только свои строки.

**Нет почты** и нет командных приглашений.

**Kinds общие на инсталляцию.** Типы не копируются пользователю. На проде `seed.Run` выключен; 9 slug пишет `EnsureKinds` при старте. Мутации kinds — любой `admin` (в том числе после register).

**Нет удаления аккаунта / каскада данных** и нет биллинга/квот.

## Auth

**`users.role` остаётся.** После register всегда `admin`. Отдельной таблицы членства нет.

**Register в v1 давал viewer.** Спринт 7 меняет это; контракты 1–6 не переписываем задним числом.

## Совместимость v1

**Сдача** — тег `v1.0.0` (общий каталог, admin+viewer). `main` после Sprint 7 этот сценарий не обещает.

**Прод:** seed выключен. Локальный seed — только для разработки, items у seed-admin.

## Инфра

По-прежнему один инстанс backend, PWA, данные только на сервере, без офлайн-CRUD.

**Тикер не каждую минуту.** Статус считается по календарному дню UTC. `TICKER_EVERY` по умолчанию 12h, плюс проход при старте процесса. Максимальная задержка смены дня — интервал тикера.
