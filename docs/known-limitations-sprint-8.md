# Known Limitations — Sprint 8

## Деплой

**Сборка на VPS.** Образы не публикуются в registry. На тарифе 2 ГБ без swap `up --build` часто падает с 137; в bootstrap кладём `/swapfile` 2G.

**Простой на rebuild.** Один инстанс backend/frontend/nginx: во время сборки сайт может не отвечать.

**Нет автоотката.** Если healthz не ожил, job красный; вернуть предыдущий SHA нужно руками (`deploy.sh <sha>`). Prune после 200 не трогает текущие теги; откат всё равно пересобирает образ.

**Prune не агрессивный.** Нет `image prune -a` / `system prune` / `volume prune`. Старые теги `<none>` и неиспользуемый BuildKit-кэш — да; живой стек и том Postgres — нет.

**Первый SSL вручную.** Actions не выпускает сертификат. Продление — контейнер certbot в prod compose.

## Секреты

**`.env` только на диске VPS.** В GitHub — SSH для деплоя. Утечка deploy-ключа = SSH на сервер, не обязательно чтение `.env`, но доступ к машине полный, пока ключ не снять.

**Деплой от того пользователя, под которым заведён ключ** (сейчас root на Beget). Отдельный unprivileged user с docker — не этот спринт.

## Триггеры

**Только `main` и ручной dispatch.** Ветки фич и PR на прод не едут. Тег сдачи `v1.0.0` не деплоим: там общий seed.

## Продукт

CD не добавляет org, viewer, почту и не включает seed на проде.
