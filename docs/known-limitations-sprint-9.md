# Known Limitations — Sprint 9

## Типы

**Нет UI создания kinds.** Добавить тип из приложения нельзя. Десятый тип — только seed / `EnsureKinds` (`mobile`). Ручки `POST /kinds` Sprint 2 в API остаются, с формы не открываем.

**Kinds общие.** `mobile` виден всем на инсталляции. Нет per-user справочника.

## Статус «Оплачено»

**Не платёж.** `paid` — ручная пометка, без эквайринга и без связи с `cost_amount`. Тикер сам его не ставит.

**Молчит колокольчик.** Пока `paid`, уведомлений нет, даже если дни порога заполнены (предоплата). Это не то же самое, что `notify_before_days: null`: дни сохраняются.

**Нет автоотката в active.** Снять «Оплачено» — снова выбрать «считает сервер» / PATCH без ручного статуса и дождаться Tick (или renew).

## Уведомления

**`null` ≠ `0`.** Ноль — напомнить в день срока. Только `null` выключает колокольчик и окно `expiring`.

**Тикер по-прежнему пачками.** Задержка смены дня — `TICKER_EVERY` (дефолт 12h) плюс Tick при старте.

## UI

**Лента только mobile.** Крупный шрифт — нижний бар PWA, не обязательный сайдбар на desktop.

## Вне скоупа

Почта, Telegram, org, шаринг, вложения, конвертация валют — без изменений.
