# Sprint 12 Checklist

Источник: [`sprint-12-plan.md`](sprint-12-plan.md). Код — только когда пользователь попросил реализовать спринт.

## 1) Обзор

- [x] Карточек «Активные», «7 дней», «30 дней», «Просрочены» нет.
- [x] По каждой валюте: всего расходов текущего месяца UTC, «осталось оплатить», «просрочено».
- [x] «Осталось» — открытые вхождения этого месяца с датой ≥ today. «Просрочено» — открытые этого месяца с датой < today. Оплаченное входит только в «всего».
- [x] День прошлого месяца в тройку не входит. Валюты не складываются. График, pie, run-rate и soonest на месте.
- [x] Тест сервиса на три числа и вторую валюту. `TestDashboardMonthSpendAndOverdueCount`.

## 2) Календарь

- [x] День не выбран — список всех вхождений месяца, у строки видна дата, оплата и снятие работают.
- [x] День выбран — только этот день. Повторный клик по нему снимает выбор.
- [x] Смена месяца снимает выбор. Пустой месяц — подсказка, не пустой сайдбар без текста.

## 3) Меню

- [x] На ширине `lg` и выше левая панель закреплена: скролл у контента, не у всей страницы.
- [x] Длинное меню скроллится внутри панели. Нижние вкладки мобильного макета остаются закреплёнными снизу.

## 4) Бейдж PWA

- [x] `overdue_count` — число открытых вхождений с датой < today по всему ряду, не только текущий месяц.
- [x] Установленное PWA ставит это число на иконку. Ноль снимает бейдж. Браузер без Badging API не показывает ошибку.
- [x] Закрытое приложение бейдж само не пересчитывает. Service worker в API не ходит.

## 5) Спека

- [x] [`api-sprint-12.md`](api-sprint-12.md) и `backend/openapi.yaml`.
- [x] [`known-limitations-sprint-12.md`](known-limitations-sprint-12.md) по факту сдачи.
- [x] `FUNCTIONAL.md`: KPI обзора — деньги месяца, не четыре счётчика.
- [x] `REPORT.md` дополнен по ходу.

## 6) DoD

- [x] `task lint` и `task test` зелёные.
