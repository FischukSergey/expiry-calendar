# Sprint 12 Checklist

Источник: [`sprint-12-plan.md`](sprint-12-plan.md). Код — только когда пользователь попросил реализовать спринт.

## 1) Обзор

- [ ] Карточек «Активные», «7 дней», «30 дней», «Просрочены» нет.
- [ ] По каждой валюте: всего расходов текущего месяца UTC, «осталось оплатить», «просрочено».
- [ ] «Осталось» — открытые вхождения этого месяца с датой ≥ today. «Просрочено» — открытые этого месяца с датой < today. Оплаченное входит только в «всего».
- [ ] День прошлого месяца в тройку не входит. Валюты не складываются. График, pie, run-rate и soonest на месте.
- [ ] Тест сервиса на три числа и вторую валюту.

## 2) Календарь

- [ ] День не выбран — список всех вхождений месяца, у строки видна дата, оплата и снятие работают.
- [ ] День выбран — только этот день. Повторный клик по нему снимает выбор.
- [ ] Смена месяца снимает выбор. Пустой месяц — подсказка, не пустой сайдбар без текста.

## 3) Меню

- [ ] На ширине `lg` и выше левая панель закреплена: скролл у контента, не у всей страницы.
- [ ] Длинное меню скроллится внутри панели. Нижние вкладки мобильного макета остаются закреплёнными снизу.

## 4) Бейдж PWA

- [ ] `overdue_count` — число открытых вхождений с датой < today по всему ряду, не только текущий месяц.
- [ ] Установленное PWA ставит это число на иконку. Ноль снимает бейдж. Браузер без Badging API не показывает ошибку.
- [ ] Закрытое приложение бейдж само не пересчитывает.
